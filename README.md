## About the Project

Pocket is a mobile app design concept focused on personal finance management.

The project explores how visual hierarchy, interface consistency, and thoughtful information organization can contribute to a more accessible and intuitive financial management experience.

The design was created in Figma, following a mobile-first approach.

## Project Goals

- Design a clean and intuitive mobile interface.
- Organize financial information through a clear visual hierarchy.
- Explore usability principles and UI consistency.
- Develop a cohesive visual identity across multiple screens.
- Strengthen my skills in UI/UX and Product Design.

## Design Process

The project focuses on the visual and structural aspects of the product, including:

- Interface layout and information hierarchy.
- Typography, colors, and spacing.
- Reusable visual patterns and components.
- Mobile interface organization.
- Consistency across screens.
